## 范围与兼容原则

- 显式声明 httpx；主进程输出统一 UTF-8，stdout 只写 JSON。
- 安装脚本检查 Python 版本和原生命令退出码，保留 .env，识别已有链接，
  使用 CODEX_HOME。提供飞书安装、授权、PATH 和可选 hosts 说明。
- 新增 import-codex-config：默认仅预览，--apply 填写空缺配置，
  已有值保留。--import-auth 明确通过 stdin 转换 provider 认证，
  已有认证不覆盖；不把凭据写入 WorkTrace 文件或输出。
- 新增 --preflight-full：分别实际探测主线路和备用 Function Calling，
  默认自检不额外请求备用。分开记录配置存在和探针完成，展示 TLS 状态。
- 技术错误分类在配置中维护，输出脱敏的修复提示。
- 长等待在 stderr 提供阶段、完成量和耗时；结果 JSON 增加结构化 warnings
  和阶段耗时，保留旧字段。所有统计由 Python 计算，不把包含阶段相加。
- Windows CI 覆盖真实进程编码、启动器、安装脚本和离线测试。
  本机 macOS 检查不能代替 Windows 实机验收。
