  `online_only`，进程环境优先，非法值报错。
- Online 主线路复用技术重试，没有备用线路；所有显式备用入口检查能力。

## Task 4: 验证和审阅

## 全局约束

不改重试配置或 SDK 隐藏重试；不修改 kube-agent-hub 或部署集群。
Python 负责计算与结构校验，模型负责语义判断。

## 审阅重点

所有入口在无 Codex 环境可运行；同线路技术与质量重试没有额外备用请求；
默认模式兼容；缓存不会跨模式复用；统计真实后端且备用切换为零。
