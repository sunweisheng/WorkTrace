## 全局约束

不改重试配置或 SDK 隐藏重试；不修改 kube-agent-hub 或部署集群。
Python 负责计算与结构校验，模型负责语义判断。

## 审阅重点

仅 Online 正式入口在无 Codex 环境可运行；同线路技术与阶段重试没有
额外备用请求；默认模式兼容；正式模型临时缓存不会跨模式复用；统计
真实后端且备用切换为零。正式缓存签名不包括模型名或完整规则配置，
独立锚点实验缓存使用另一套规则，不能套用正式续跑保证。
